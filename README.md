# Background Changer Project

A modern and responsive Background Changer web application built using React and Tailwind CSS.
Users can dynamically change the background color of the page with smooth UI interactions and a clean interface.

---

## Features

* Dynamic background color changing
* Responsive design
* Smooth transitions
* Modern UI using Tailwind CSS
* React state management using `useState`
* Interactive color buttons

---

## Tech Stack

* React
* Tailwind CSS
* JavaScript
* Vite

## Installation

Clone the repository:

```bash
git clone https://github.com/Anshdeep-code/background-changer-project.git
```

Move into the project folder:

```bash
cd background-changer-project
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
